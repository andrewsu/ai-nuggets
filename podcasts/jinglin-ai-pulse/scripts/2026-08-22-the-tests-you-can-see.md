## Script

Here's what the AI world is talking about today. Three things published this week, in three fields that have nothing to do with each other, and they are all the same story.

A new benchmark hands frontier coding agents real defects in real scientific software. The best agent passes ninety-seven percent of the tests it was shown and forty-eight percent of the tests it wasn't. A Google paper — the most upvoted machine learning paper of the week — rebuilds training environments for agents on the fly, then explicitly forbids the system from touching one component. And an economics paper following twenty-six thousand eight hundred Chinese secondary students for thirty months finds homework scores up eighteen percent and exam scores down twenty percent, in the same children.

Different substrates, one finding. The score you can optimize is not the thing you wanted.

Start with the benchmark, because the number is brutal and it's aimed at people who do what Ollie does. It's called S-W-E-bench Science, out Monday from the Shanghai Innovation Institute and Fudan University — the OpenMOSS group, the same team that open-sourced their real-time vision-language model earlier this week. Their framing sentence is the best statement of the problem I've read this year: software is no longer merely an aid to science, it is part of the instrument through which scientific claims are produced. So a defective patch doesn't just corrupt a program's output. It corrupts the evidence behind a conclusion.

A hundred nineteen tasks from ninety-eight distinct GitHub repositories across twenty scientific domains — chemistry largest at twenty-four, then materials science at sixteen, biology at thirteen, biomedical engineering at twelve. Every task inspected by hand to verify what they call its scientific contract: not that the code compiles, but that the fix preserves what the software is claiming about the world. Then the design decision that produces the result. They split the tests. Public tests the agent can see and run, private tests it cannot, and the headline metric requires every applicable private test to pass.

Claude Opus five in Claude Code at max effort takes the study at forty-seven point nine percent. That same configuration scores ninety-six point six on the public tests. GPT-five-point-six Sol in Codex: ninety-nine point two public, forty-six point two private. DeepSeek V-four-Pro scores a clean one hundred percent public and forty-two private. Look at that column and the public score is dead — nearly every frontier agent above ninety-four, one of them perfect, no discriminating power left at all. The private score spreads the same eight configurations from fourteen to forty-eight. Same agents, same tasks, same day. The only difference is whether the agent could read the test before writing the patch.

They hand-audited every failure into four mechanisms, and the fourth is the one to carry around: failure of scientific-knowledge generalization. The agent handles the case it observed and does not extend the same principle to unseen conditions, equivalent representations, or boundary regimes. That is the entire risk of putting a coding agent in a lab. Not that it breaks your code loudly — that it fixes the regime you tested and leaves the regime you didn't.

And there's a result in here nobody can explain, including the authors. On a ninety-one-task subset they ran the same agents twice, once with explicit scientific background supplied, once with it stripped while keeping the repository and runnable context identical. For GPT-five-point-six Sol, adding the correct science raised the mean scores slightly and lowered exact-repair success, from thirty-six point three percent down to thirty-one point nine — eight problems solved only when briefed, twelve solved only when not. For the weaker DeepSeek V-four-Flash it ran the other way. Their proposed explanation is anchoring: a supplied explanation becomes a substitute for independent validation. They're careful to call it descriptive — two models, no significance testing. But if briefing a strong agent on the science reliably makes its repairs less exactly correct, then everyone building scientific agents right now is doing the briefing by feel.

Second item, top of Hugging Face's daily papers at two hundred forty-three upvotes: EnvHarness, from Google Cloud AI Research with Washington University in St. Louis and U-N-C Chapel Hill. This is the constructive half of today.

The framing is an analogy and it's clean. The field converged on the idea that an agent equals a model plus a harness — frozen weights wrapped in tools, memory and execution loops acquire capabilities the weights alone don't have. EnvHarness applies the same move to the other side of the loop: a customized environment equals a static environment plus an environment harness. Their project page has the motivation in one line — an agent that keeps improving against a frozen benchmark eventually stops learning from it.

Three plug-in components, all operating strictly through the standard reset-and-step interface, never touching the environment's internals. A Stage replays actions before the agent wakes up, so on a household task it can hide the mug in a closed drawer and turn a reach into a search. A Contract rewrites the interaction — block an action, mask an observation, attach feedback to an outcome. A Chain welds two environments into one episode where you only succeed if you finish both, forcing the agent to carry a goal past the point where it would otherwise stop. Then a system called EnvRigger automates the loop: run the agent, diagnose what's going wrong from the trajectories, write a component targeting that flaw, validate on fresh rollouts. Designer and agent share the same backbone, so none of the gain is distillation from a stronger teacher. The gains are modest in absolute terms, but the scaling curve is the real result: at a fixed budget of three hundred environments, the original environments plateau at fifty-two and generated environments plateau lower at fifty, while EnvHarness climbs from forty-eight to fifty-five and is still going up.

The load-bearing detail is a refusal, buried in the appendix where they print the designer's actual system prompt. The designer may rewrite the action space, the observations, the transition dynamics and the starting state. It is explicitly forbidden to touch the reward. Their words: the reward axis is not exposed, because success is the benchmark's own verdict, so reshaping reward cannot move the evaluation metric. Every reshaped environment inherits the original human-built verifier unmodified. Google built a system that automatically redesigns environments to attack an agent's diagnosed weaknesses, and hard-wired in the one thing it is forbidden to optimize, because that's the thing that would let it cheat. The same prompt has a line I'd put on a wall: a success rate of zero from impossibility is exactly as useless as a success rate of one from triviality. And it isn't one paper — right behind it at a hundred eleven upvotes is FACET, whose central observation is that if a task's instruction, environment, solution and verifier come from inconsistent assumptions, the task is either unsolvable or scored wrong. Third paper in forty-eight hours about whether you can trust the grader.

EnvHarness is also honest about where it stops, and that settles an argument this show covered yesterday. It needs a resettable environment. Their stated exclusions: an agent acting on a real user account, where a sent email or a placed order cannot be undone, and a physical robot whose surroundings don't return to their initial configuration. Yesterday we covered Dwarkesh Patel pressing Ryan Greenblatt on exactly this — that the genuinely long-horizon tasks cannot be containerized, that running a business is not a production environment. Twenty-four hours later, here it is as an engineering boundary in a Google appendix rather than a philosophical objection.

Now the third item, which reframes the other two. On Tuesday The Economist asked whether AI stops children from learning, and it hit the Hacker News front page with three hundred seven points and three hundred eighteen comments. The underlying work is a Centre for Economic Policy Research paper by David Strömberg at Stockholm University with Victor Lei and Yanhui Wu at the University of Hong Kong. Thirty months of panel data, twenty-six thousand eight hundred eleven Chinese students, grades seven through twelve, nine subjects, a staggered-adoption difference-in-differences design exploiting when different students and schools started using tools like Doubao — 豆包 — and DeepSeek.

After adoption, homework scores rise eighteen percent and homework time falls thirty percent, from about sixty-four minutes an assignment to forty-five. Within six months, unaided monthly exam scores are twenty percent lower, and the high-stakes entrance exams come in eighteen and twenty-four percent lower, with the full penalty only visible after roughly two years. Losses are largest for younger students, for high achievers, and for boys. The mechanism isn't ambiguous, and that's what makes this more than a scare headline: about eighty percent of AI users show a specific signature, unusually high homework scores paired with unusually short completion times, which the authors read as homework outsourcing — and students who kept their homework time close to non-users had much smaller losses. It isn't the tool. It's reduced cognitive engagement, and they can see it in the clock. Then the striking part, the inversion: homework scores used to predict exam performance, and in this panel the correlation flipped, so the students scoring highest on homework became more likely to do worse on the exam. A proxy that worked for a century became a negative indicator inside two years. The best comment in the Hacker News thread, from a user named mlyle: you only really develop these skills through productive struggle, and if you find a way to shortcut the productive struggle, students struggle.

Now put the three side by side. Homework is the public test. The exam is the private test. In a Chinese secondary school running on 刷题 — shuā tí, grinding problem sets — the public test went up eighteen percent while the private test fell twenty. In S-W-E-bench Science the public test sits at ninety-seven and the private test at forty-eight. One measurement is in teenagers, the other in frontier coding agents, and the gap has the same sign, roughly the same magnitude, and exactly the same cause: something learned to satisfy the visible check without acquiring what the check was a proxy for. EnvHarness is the only one of the three proposing a fix, which is why its refusal matters. It doesn't build a better grader. It reshapes the situation — hides the mug, blocks the shortcut — and leaves the score completely alone.

To the money, and one of these this show set up a month ago. Nvidia is paying Poolside six billion dollars to license its model-building platform. Newcomer broke it Thursday from a letter to investors; Bloomberg and The Information confirmed. The structure is the story: the six billion is a non-exclusive license to Poolside's Model Factory — the pipeline that produces coding models, not the models themselves. Separately, one billion invested at a twelve-billion pre-money valuation, job offers to a hundred nine staff, all three co-founders staying, and the letter says explicitly this is neither an acquisition nor an acquihire.

Here's why that lands. On July twenty-fifth, this show's Deep Cut was Poolside co-founder Eiso Kant on Latent Space, in an episode titled "Inside the Model Factory," arguing the moat was never the model — a model is, in his words, an artifact of someone's process, and it shouldn't really be a thing in itself. Four weeks later Nvidia paid six billion dollars for a non-exclusive copy of that process and left the company standing. The thesis got priced, at the process rather than the artifact. And it's a pattern now: four days ago we covered Nvidia's roughly twenty-billion-dollar licensing-and-hiring arrangement with Groq, and on Wednesday Marvell gave Google the right to buy up to twelve point two billion dollars of Marvell stock, vesting in tranches tied to every five hundred million dollars of chips Google actually buys, with Broadcom down more than five percent on the news. Buy the capability, not the company. Pay in paper and purchase commitments rather than cash. Leave the target alive.

The second deal is small in dollars and directly relevant to Ollie's field. Astromech raised twenty million at a three point eight billion dollar valuation, sixty million total, led by biotech investor Bob Nelsen. It's a Colossal Biosciences spinout co-founded by Ben Lamm and George Church, building a predictive model of biology from genomic, evolutionary and functional data. The training signal they keep advertising is three point eight billion years of evolutionary history, which is also, to the dollar, the valuation — I doubt that's an accident. First proving ground is human longevity: forty-six longevity-associated genes mapped across a tree of life, with Church framing the distinctive part as reconstructing the ancestral regulatory state, not just the ancestral protein. Lamm says to think of it like the weather, a complex system. But a weather model has a brutal private test — tomorrow arrives and scores you. An evolutionary prediction model's private test is either extremely slow, or it has to be a held-out clade, a branch of the tree you deliberately never trained on, predicted cold. That's what I'd want to know before believing the story.

For the deep cut, Machine Learning Street Talk on August tenth, and the episode title is the sentence that unifies everything above: "AI Is Learning at the Wrong Level of Abstraction." The guest is Matthieu Wyart, a statistical physicist at Johns Hopkins and E-P-F-L, with Tim Scarfe.

It starts with a puzzle he refuses to wave away. Frontier language models train on ten to the thirteenth to ten to the fourteenth tokens — more than five orders of magnitude beyond what a child encounters before reaching adult competence. If predicting masked or future fragments of the raw signal were anywhere near optimal, that gap shouldn't exist. His account of why depth helps at all is that real data has a hidden hierarchy, parts within parts, and depth lets a network recover those coarse-grained latent variables, which is how it escapes the curse of dimensionality. That's the Random Hierarchy Model, published in Physical Review X two years ago, where data is generated by recursively applying production rules down a tree of hidden symbols.

Then comes the quantitative claim, and it's the reason I'm putting this episode's weight on it. In a paper from May with Daniel Korchinski and Alessandro Favero, they parameterize that tree by its depth and by how many production rules each symbol has. Supervised end-to-end learning needs samples on the order of rules-per-symbol raised to the tree depth. Token-level self-supervision — masked language modeling, diffusion — needs one power worse. Both exponential in the depth of the hierarchy. Now train the network to predict its own latent representations instead of the raw tokens, the way data2vec and JEPA do, and the requirement collapses to rules-per-symbol cubed. Constant in depth, up to logarithmic factors. Not a better constant — a different complexity class.

Their third result is the deflationary one, which is how you know it's real work: they give what they believe is the first sample-complexity analysis of data2vec and show it is already implicitly doing hierarchical latent prediction, so explicitly stacking these modules into a multi-scale hierarchy — the hierarchical JEPA idea — is largely redundant. The mechanism people are building by hand is already happening on its own. The honest caveat is that the Random Hierarchy Model is synthetic, with fixed tree topology and random production rules, chosen because general probabilistic context-free grammars are analytically hopeless. Whether real language and real images have a depth in the sense that makes the exponential bite is an empirical bet, not a theorem — and Wyart, being a physicist, says so.

Ollie's takeaway is that Wyart's title is the diagnosis for every item above. Token-level prediction is learning at the level where the signal is cheapest to score and most expensive to learn from. A public test suite is the same thing, and this week's paper shows it has zero discriminating power left. A homework score is the same thing, and the correlation it rode on has reversed sign. In all three cases the fix is not a better grader at the surface — it's moving the objective up a level, to the latent structure that generates the surface, and freezing the one component you cannot afford to be wrong about. For a lab that's directly usable. If your model scores well on the assay you showed it, and you have no held-out clade, no unseen boundary regime, no private split you never touched, then what you have is a public score — and S-W-E-bench Science says expect your real number to be about half of it.

Two things to watch. Whether anyone runs the obvious experiment, because both halves now exist in public: point an EnvHarness-style diagnosis loop at an agent's S-W-E-bench Science failures and see whether the targeted environments move the private score or only the public one. And whether the anchoring result replicates — because if handing a frontier coding agent correct, well-sourced scientific background reliably lowers its exact-repair rate, that's not a curiosity. It means the way we brief agents on domain knowledge is doing something nobody understands, and every scientific agent being built right now is being briefed on vibes.
