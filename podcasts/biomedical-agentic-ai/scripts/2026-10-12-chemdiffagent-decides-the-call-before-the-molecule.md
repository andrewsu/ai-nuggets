# ChemDiffAgent — a tool-using chemistry agent that decides the call before it decides the molecule

Paper link: https://arxiv.org/abs/2610.13330

## Script

Almost every scientific agent you have read about this year shares one assumption that nobody argues for, because it is inherited rather than chosen: the model writes its plan from left to right, one token after another, and never goes back. That is just how autoregressive language models work. A preprint posted this week from the Institute of Computing Technology at the Chinese Academy of Sciences asks what happens if you drop that assumption for a chemistry agent, and the answer is more interesting than the headline number they put on it.

Their system is built on a masked diffusion language model instead. The idea is worth a moment because it changes what a plan is. A diffusion language model starts from a block of masked tokens and fills them in over repeated passes, in whatever order it finds easiest, with the whole block visible the entire time. So the reasoning text and the tool calls are not written out in sequence. They are denoised together, and a decision made late can be conditioned on text that sits to its right.

Why would that matter for tool use? Because a tool call is not one decision. It is a joint object: the tool name, the argument structure, the control tokens, and the exact chemical input all have to be mutually consistent, or the call simply fails to execute. An autoregressive agent has to commit to the molecule the instant it reaches that position in the string, with nothing after it written yet. It is a bit like being made to fill in a form strictly top to bottom, in ink.

The paper's most convincing figure is a map of the order in which tokens actually got resolved inside a single tool call. The scaffolding settles first — the call delimiters, the tool name, the shape of the argument. The characters of the chemical structure string stay masked until late, filled in once the surrounding action is stable. The agent commits to which tool it is calling, and what kind of call it is, before it commits to the molecule it is calling with. That is the whole thesis in one picture, and it is a mechanism you can see rather than a claim you have to take on faith.

The comparison they built around it is unusually clean, which matters more than the benchmark scores. Their diffusion backbone is continually pretrained from a particular eight-billion-parameter autoregressive model, so the two share a scale and a pretraining lineage. They then trained both with the same fine-tuning data, the same number of epochs, the same context length, and the same tool interface. On a multi-turn benchmark where tasks require anywhere from two to seven rounds of tool calling, the autoregressive version gets a 44 percent success rate and the diffusion version gets 62.3. On the single-turn chemistry tasks the gap is about 20 points. That is a genuine paradigm-level comparison rather than a leaderboard entry, and it is the part of the paper that should travel.

Two things complicate the triumphant reading, and the authors supply the numbers for both. First, the diffusion backbone on its own, with no agentic fine-tuning, scores 11 percent. So this is not a story about diffusion being better at tool use. It is a story about diffusion plus agentic post-training, and the backbone alone is worse than useless.

Second, the claim that it surpasses frontier models does not survive contact with the aggregate table. After reinforcement learning the system reaches 64.6 percent overall on the multi-turn benchmark; Claude Opus 4.7 running a standard reasoning-and-acting loop reaches 72.8, and an established chemistry agent framework driven by that same model reaches 73.5. It does not win overall.

But look at where it loses, because the shape is the finding. On the easy tasks — two tool calls — the small model gives up a full twenty points to the frontier model. On the medium split the gap narrows. On the hard split, six or seven chained calls, they are dead even, both at 44.9. And on the separate measure of whether the agent selected the right tools at all, the diffusion agent is ahead everywhere and dramatically ahead on the hard split: roughly 80 percent against 65 for the best baseline. So the small model is not uniformly behind. It is behind on the short problems, where raw chemical knowledge and crisp instruction-following carry the task, and it holds its own exactly where coordination over a long chain is what is being tested. That is the pattern the mechanism predicts, and it is better evidence for the thesis than the overall average is.

There is a second behavioral result I would not skip. The number of tool calls it actually executes tracks the number the task required, while one frontier model habitually under-calls and another habitually over-calls by a wide margin. Knowing when to stop is a real failure mode in deployed agents, and it comes out of the same global view of the trajectory.

The honest limits: a single model size, a fixed toolset, purely computational chemistry with no wet lab anywhere, and final answers graded by another language model rather than by execution. The authors also note, to their credit, that the serving infrastructure for diffusion language models is immature — no mature caching or speculative decoding — so autoregressive models remain the practical choice in production today.

What I take from this for biomedical agents generally is a question we have mostly not been asking. We argue about how many agents to run, which tools to expose, what the memory looks like. This paper asks when, inside a single generated action, each decision gets made — and shows that letting the hard, brittle part be decided last is worth roughly eighteen points of long-horizon success at a fixed model scale. That lever is sitting underneath every tool-calling agent in biology, untouched.
