# Agentic AI rewrites legacy bioinformatics into Rust — with classic static analysis as the guardrail

Paper link: https://arxiv.org/abs/2608.13029

## Script

Today's nugget is a solo preprint from Johan Henriksson at Umeå University and SciLifeLab in Sweden, and it's about the least glamorous, most valuable job in our field: keeping old software alive. The claim is that agentic AI, paired with classic static analysis, can rewrite legacy bioinformatics code into Rust at scale — and he backs it with a translated single-cell pipeline that's now eighty times smaller than the version it replaced.

Start with the pain, because you already feel it. Bioinformatics runs on a graveyard of unmaintained code — Perl, Fortran, decade-old C — written by a postdoc who left, in a language nobody in the lab still reads. Dynamically typed languages like R and Python burn more than fifty times the energy of a compiled language on some workloads, leak memory, and can't touch modern hardware efficiently. And the way we glue it all together — Conda resolving conflicting versions, everything wrapped in a container per operating system — is its own layer of fragility. The technical debt is enormous, and nobody's funded to pay it down.

So the obvious move is: point Claude or Codex at the code and say "translate this to Rust." Henriksson tried that first, and this is the important part — it fails in a way that looks like it worked. The models silently swap a less-than for a greater-than. They pick the wrong integer type and cause an overflow. They reorder floating-point operations, which is fine in theory but not in silicon, so p-values drift and gene lists come back in a different order or get cut at a threshold. They quietly replace a real algorithm with a naive one, or reuse the wrong function because two looked similar, or drop the SIMD optimizations. Every one of those produces code that compiles, runs, and gives you subtly wrong answers.

Here's the insight that makes the paper. Large language models are bad at precisely tracking global code structure — but that is exactly what classic compiler algorithms are great at. So instead of trusting the model to police itself, he builds deterministic guardrails around it. Both the original and the candidate translation get parsed into syntax trees with tree-sitter, and then three tools check the agent's work. The first, a code-complexity comparator, lines up the two call graphs function by function and compares their types, their cyclomatic complexity, their logical expressions, against an explicit mapping of which original function became which Rust function. The second instruments the code and hashes every function's inputs and outputs, so a behavioral divergence — or a function being called the wrong number of times — shows up immediately. The third runs the original and the translation in two lockstepped debuggers in parallel, which is basically a bisimulation check for equivalence. And the whole translation is held to a strict rule: one original function becomes exactly one Rust function, no new helpers, same directory structure. That one-to-one discipline is what keeps the result auditable — and it's what lets those static tools do their job. Interestingly, the agents reached for the first two tools on their own; the lockstep-debugger one they never picked up unless told, a little window into what their training rewards.

Now the payoff. Across about forty attempts, thirty-five packages — spanning next-gen sequencing, imaging, and upstream libraries — reached a tested, benchmarked, production-usable state. But the showcase is his own tool, Bascet, a single-cell pipeline for microbial metagenomics. By translating every upstream dependency into a Rust library and letting Cargo handle versions, he deleted Conda and containers entirely. The result ships as one two-hundred-megabyte binary — eighty times smaller than the container it replaced. Build time dropped from twenty minutes to one or two. Key steps run over three times faster, because once dependencies are libraries instead of command-line tools, you can pass data by reference and skip the startup and copy overhead. It cross-compiles to Apple's M-series chips, and — because he stripped out the Unix-specific calls — it became the first single-cell toolkit that runs on native Windows, no Linux subsystem required.

He's refreshingly honest about the ceiling. Translation does introduce bugs, and the AI-generated tests were not good enough — you have to regression-test against real data comparing old output to new. Floating-point order-of-operations was a recurring hazard. Metaprogramming-heavy code beat it outright; two attempts at BLAST both failed because so much of BLAST is code that generates code. C translates to unsafe, non-idiomatic Rust that needs a second cleanup pass. And the agents would occasionally paper over a memory bug by just leaking the memory. But — and this cuts the other way — the translation also surfaced at least three real bugs in the original software, including a use-after-free. His bet is that as the models mature, bugs fixed will outnumber bugs introduced.

Why this belongs on your radar: it's agentic AI aimed at the open-science infrastructure problem — the maintenance work that's too expensive to do by hand and too important to skip. And the methodological lesson is one this show keeps circling back to. Don't trust the model's own judgment about whether it got the code right. Wall it behind a deterministic verifier — here, decades-old static-analysis tooling — and keep a human checking against real data. The prompts and the tools are shared. The provocative version of the thesis is that Rust could become the one language a bioinformatician ever has to learn. Whether or not that lands, the recipe — agent plus classic verifier plus real-data regression — is one you can borrow tomorrow.
