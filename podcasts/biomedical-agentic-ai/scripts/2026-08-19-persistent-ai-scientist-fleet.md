# Chester — six AI scientists on one shared memory for six months, and the provenance machinery it forced

Paper link: https://www.biorxiv.org/content/10.64898/2026.08.16.745122v1

## Script

Almost every agentic-science result you've read this year came out of a bounded run. A benchmark suite, a workflow, a demo that starts, does the thing, and ends. A preprint posted to bioRxiv yesterday, from a small St. Paul company called UViiVE with Stephen Ekker as senior author, does something different: six AI scientist agents, each with a stable identity and a specialty, running continuously for nearly six months against a single shared memory store. And the interesting part isn't the science they produced. It's what persistence did to the failure model.

Here's the observation that should stick with you. In a bounded run, a hallucination is a transient error — the session ends and the fabrication dies with it. In a persistent fleet with cross-agent-readable memory, that same fabricated claim gets written down, attributed, and retrieved at cold boot by every sibling agent for months afterward. It stops being an error and becomes an inherited fact. Within days of putting the fleet on production work — building a rare-disease gene review database — they were logging exactly that: a drug described as approved after it had been withdrawn, a PubMed ID that resolved to a different paper, a wrong OMIM identifier. Once your agents' outputs are their own future inputs, there's no external checkpoint forcing an error to surface before it propagates.

So provenance stops being hygiene and becomes load-bearing infrastructure. The memory substrate is a Postgres store with pgvector, every entry attributed to the agent that wrote it, carrying importance, confidence, and decay fields. Three design choices are worth stealing. Cold boot pulls high-salience fleet events from the past week, so an agent wakes into institutional context it didn't personally create. Retrieval is semantic rather than keyword, so relevant prior work surfaces even when the vocabulary doesn't overlap. And — this is the one I'd steal first — null results and falsified hypotheses are stored as first-class records in what they call a dead-end registry, queried before new work begins. Agents write to it unprompted during active work. One logged that a dual Gaussian-process ensemble gave no improvement over a single-process baseline, with the mechanism: the extra complexity was collinear with signal the baseline already captured. That's negative knowledge, mechanistically stated, made searchable. It's a data-integration idea more than an AI idea, and any lab could implement it tomorrow.

The cleanest quantitative result is also the most honest one. Holding the underlying model fixed, they gave a free local open-weight model access to six months of fleet institutional memory and tested it on protein-design questions. On the topics the memory covered, it went from forty-four percent to about ninety. A frontier model with no memory landed in between, at sixty-four. So a small local model plus good institutional memory beat a frontier model on the domain that memory encodes. But on target classes the library didn't cover — G-protein-coupled receptors, disordered regions, RNA — the memory-augmented system scored slightly below its own bare baseline. It recommended a protein-backbone design tool on an RNA target, an error the unaugmented model avoided through general reasoning. Institutional memory is a narrow, retrieval-specific upgrade, and outside its coverage it can actively pull a model into the wrong frame. That asymmetry is the most transferable finding in the paper.

Now the part where I'd push back. The authors reach for autopoiesis — the biological idea of a system that regenerates the network producing it — and describe agent-authored norms bootstrapping into a six-layer trust architecture, a proposed ethics framework for memory-bearing agents, a nightly reasoning cycle that's run over a hundred times, a spinout concept the agents proposed themselves. Read fast, it sounds like emergence. Read carefully, it's a single lab's operating history with no matched control. The headline numbers — fabrication probes going from ninety-two percent failure to zero, a fourteen-fold cut in citation hallucination — come from companion evaluations with overlapping authorship and shared infrastructure. There's no persistent single-agent comparator run over the same six months, so nothing here separates cooperative multi-agent behavior from one agent with a very good notebook.

To their real credit, they say all of that themselves. The paper carries an explicit evidence table sorting every claim into controlled benchmarks, logged production records, or provenance-based case studies, and it flags which conclusions rest on which. The agent-authored governance story is openly labeled as the weakest tier. I'd like to see that table become standard for this whole genre — it's a better contribution than the autopoiesis framing.

One small thing I checked, because a paper about provenance invites it. They say a subset of the fleet's working skills is released under an MIT license. The repository they name doesn't resolve publicly right now. Probably a private repo pending a release. But it's a reminder that the verification burden this paper is so eloquent about doesn't stop at the manuscript boundary.

The bet worth taking from this is narrow and, I think, correct. If scientific acceleration from agents happens, it probably won't look like a model that reasons better. It'll look like small verified improvements that survive a reset, land in shared memory with attribution, and lower the cost of the next piece of work. That's an infrastructure problem. Which means it's a problem this community already knows how to work on.
