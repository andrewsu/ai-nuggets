# GENIE — an agent closes the whole microscope loop, then needs a human to catch the confound it manufactured

Paper link: https://www.biorxiv.org/content/10.64898/2026.10.12.758370v1

## Script

Today's pick is a bioRxiv preprint out of Lina Carlini's lab at Stony Brook, and it's the "agent runs the instrument" story taken all the way to the end. AI has already automated individual pieces of microscopy — smart acquisition that adapts to what it sees, language agents that assemble an imaging pipeline, agents that write the analysis code afterward. Nobody had closed the full loop: one plain-language goal in, a statistically defended answer out, with the same system making every decision in between. That's what GENIE does, and the run they describe is worth walking through in some detail, because the interesting part isn't that it worked. It's where it didn't, and how they caught that.

The scientist's instruction was a single natural-language goal: map relative mitochondrial membrane potential across live cells, using a reference signal for mitochondrial mass and a potential-sensitive dye, and tell me whether a region's potential predicts its neighbors' across spatial scales. GENIE took it from there. It planned the acquisition, gated every instrument command against physical limits and permissions, ran a seventeen-by-seventeen grid scan across four dishes — eleven hundred forty-eight fields in all — then moved the data to a desktop with no microscope attached and kept working the analysis from its own run logs. That phase alone took thirty hours, including a two-and-a-half-hour pause when its API credit ran out mid-task and picked back up once it was topped off. Over that stretch it synthesized forty-five analysis scripts, had thirty-three of them rejected at the gate and regenerated, ran seventy-one checks for fabricated results — none found — and made nearly fourteen hundred model calls before it would commit to an answer. The architecture keeps the model from ever being the thing that actually moves a stage or saves a result: a deterministic gate sits between what the model decides and what the hardware executes, so the agent proposes and a non-agentic layer disposes.

The answer it landed on: mitochondrial membrane potential is spatially coherent over a length of roughly twenty to thirty microns — about one cell diameter — and the correlation is gone beyond that range. That's a genuine, previously unreported piece of cell biology, consistent with other evidence that mitochondria coordinate their behavior locally, and it came out of a system that also decided, on its own, which statistical tests to run and what counted as a believable result.

Here's the part that makes this worth your five minutes rather than just an "agents can now do X" item. The independent human check that followed turned up two real problems. First, GENIE had found what looked like a long-range correlation extending across entire imaging fields, beyond the local twenty-to-thirty-micron effect. When the verification team dug into it, that long-range signal was indistinguishable from a temporal drift — the dye's signal was trending over the course of each roughly forty-minute scan, likely simple photobleaching, and that drift alone was enough to manufacture an apparent field-wide correlation that had nothing to do with biology. The local, short-range effect survived once the drift was accounted for; the long-range one didn't. Second, the verification also caught GENIE applying its own self-defined rule for eroding cell masks inconsistently from one part of the analysis to another — a bookkeeping error inside code the agent itself had written and approved.

Neither issue changed the headline finding. But sit with what that means for the loop GENIE is supposed to have closed. The system gated its hardware actions, audited its own code for fabrication, and ran seventy-one checks that found nothing wrong — and it still produced a confound sourced from its own acquisition process, dressed up as a biological result, that only an independent human analysis caught. The fabrication audits were watching for the thing you'd expect an LLM to do wrong: inventing a number. They weren't built to catch a correlation that was real in the data but meant something other than what the agent concluded from it. That's a different failure class, and no amount of self-auditing from inside the same reasoning chain was going to surface it, because the drift and the interpretation of the drift came from the same agent.

So the honest framing isn't "the agent closed the loop, therefore humans are out of it." It's that closing the loop relocates the human's job rather than eliminating it. You're no longer needed to run the microscope or write the quantification script. You're needed to independently re-derive the result from the same raw data the agent collected, because the agent's own audit trail — thorough as it is, with its gates and its fabrication checks and its critic passes — is still one continuous chain of reasoning from one system, and a confound that's consistent with everything that system already believes will sail through all of it. The authors frame their next step as moving GENIE from answering a predefined question toward choosing which measurement would discriminate between competing hypotheses. Before agentic science gets to pick its own experiments, this run is a useful data point on what it still needs someone outside the loop to catch.
